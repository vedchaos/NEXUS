# NEXUS Vision Skill

Visual perception for NEXUS.

## Capabilities
- **Screenshot** — Capture screen or region
- **OCR** — Read text from any image
- **Analyze** — Colors, metadata, structure
- **Find Text** — Search for specific text on screen

## Commands
- "screenshot lelo" → take screenshot
- "screen pe kya hai" → screenshot + OCR
- "ye image padho" → read text from image
- "file explorer mein kya hai" → find text on screen
