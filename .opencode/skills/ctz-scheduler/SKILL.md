# CHAOS TYPE ZERO Scheduler Skill

Hinglish-aware task scheduler.

## Time Expressions
- "agle 5 minute mein" → 5 minutes from now
- "kal subah 9 baje" → tomorrow 9 AM
- "roz raat 10 baje" → daily at 10 PM
- "hafte mein ek baar" → weekly

## Commands
- "schedule karo" → create scheduled task
- "tasks dikhao" → list scheduled tasks
- "task hatao" → remove scheduled task
- "abhi kar do" → execute immediately
