# NEXUS Recon Skill

Reconnaissance toolkit for NEXUS.

## Recon Types
1. **Passive** — DNS, WHOIS, subdomains (no direct contact)
2. **Active** — Port scanning, service detection
3. **OSINT** — Public data gathering

## Commands
- "recon karo target.com" → full recon
- "subdomains dhundho" → subdomain enumeration
- "DNS check karo" → DNS record lookup
- "ports scan karo" → port scan
