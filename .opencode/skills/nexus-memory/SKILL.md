# NEXUS Memory Skill

3-tier memory system: RAM → SQLite → ChromaDB.

## Commands
- "yaad rakhna" → save to memory
- "puchna tha" → search memory
- "memory dikhao" → list recent memories
- "purani memory saaf karo" → clean old memories

## Memory Types
- **note** — General knowledge
- **task** — Completed task record
- **finding** — Discovery or insight
- **decision** — Decision made and reasoning
