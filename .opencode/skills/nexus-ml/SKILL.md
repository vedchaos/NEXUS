# NEXUS ML Skill

Machine learning pipeline for NEXUS.

## Capabilities
- **Train** — Classification and regression models
- **Predict** — Make predictions with saved models
- **Evaluate** — Test model accuracy
- **Pipeline** — Auto feature engineering

## Supported Algorithms
- Random Forest
- Gradient Boosting
- SVM
- Logistic/Linear Regression

## Commands
- "model train karo" → train on loaded data
- "predict karo" → use saved model
- "accuracy check karo" → evaluate model
- "data visualize karo" → generate plots
