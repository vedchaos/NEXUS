# NEXUS Deploy Skill

Deployment and CI/CD for NEXUS.

## Capabilities
- **Build** — Compile and package applications
- **Docker** — Container management
- **Deploy** — Push to production
- **CI/CD** — GitHub Actions, pipelines

## Commands
- "deploy karo" → deploy application
- "build banao" → create build
- "Docker setup karo" → containerize app
- "release karo" → create release
