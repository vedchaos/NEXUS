# CHAOS TYPE ZERO Code Review Skill

Strict code review for CHAOS TYPE ZERO.

## Review Checklist
1. **Bugs** — Logic errors, edge cases, null checks
2. **Security** — SQL injection, XSS, secrets in code
3. **Performance** — O(n²) loops, unnecessary allocations
4. **Style** — Naming, formatting, documentation
5. **Tests** — Missing tests, edge case coverage

## Severity Levels
- **CRITICAL** — Security vulnerability or data loss risk
- **HIGH** — Bug that will cause runtime error
- **MEDIUM** — Code smell or maintainability issue
- **LOW** — Style or minor improvement

## Commands
- "code review karo" → full review
- "bugs dhundho" → find bugs only
- "optimize karo" → performance improvements
- "refactor karo" → code structure improvements
