# NEXUS Voice Skill

Voice interaction for NEXUS.

## Capabilities
- **Speak** — Read text aloud (pyttsx3)
- **Listen** — Record mic and transcribe (Whisper)
- **Transcribe** — Convert audio file to text
- **Save** — Convert text to audio file

## Commands
- "bol ke sunao" → speak the response
- "sunno" → listen to mic for 5 seconds
- "ye audio suno" → transcribe audio file
- "audio banao iska" → save text to audio file

## Voice Settings
- Rate: 175 (default)
- Volume: 0.9 (default)
- Language: English (switchable)
