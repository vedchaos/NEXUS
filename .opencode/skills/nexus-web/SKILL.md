# NEXUS Web Skill

Web interaction for NEXUS.

## Capabilities
- **Browse** — Navigate and interact with websites
- **Scrape** — Extract data from web pages
- **API** — Call REST/GraphQL APIs
- **Fetch** — Download files and content

## Commands
- "website kholo" → open and analyze website
- "data scrape karo" → extract data from page
- "API call karo" → make API request
- "file download karo" → download from URL
